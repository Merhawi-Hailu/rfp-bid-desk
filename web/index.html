    CV freshness

    Are the CVs up to date?

    Tenders score key personnel on current CVs. Each CV should be updated at least once in the period below. The date is read from the CV text (for example "CV last updated: 14 June 2025"). If there is none, the file's saved date is used. You can type a date or email in any row.

    Certificate and ID proof

    Do the CVs match the certificates and ID on file?

    For each person, this reads the certifications listed in their CV and looks for a copy of each certificate. It also checks that an ID document is on file, that the name on it matches the CV, and that it has not expired. When each person has their own folder (for example "Merhawi Hailu" holding their CV, certificates and ID copy), every file in that folder is treated as theirs. It also shows certificates on file that the CV does not mention. If a file is named in an unusual way, link it by hand. ID checks run in this browser and ID documents are never sent to the AI.

    The page shows a quick check by name and certification code. Press Check with AI to have the AI read each CV and every file in the person's folder. Results are kept until the files change.
